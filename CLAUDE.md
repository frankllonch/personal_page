# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev      # Start dev server with Turbopack
npm run build    # Production build with Turbopack
npm run start    # Start production server
npm run lint     # Run ESLint
```

No test suite is configured.

## Architecture

**Framework:** Next.js 16 App Router + React 19 + TypeScript
**Styling:** Tailwind CSS 4, with a small set of plain classes in `app/globals.css` (`.label`, `.boxes`/`.box`, `.rule`, `.soft`)
**Motion:** only the GSAP text scramble on hover (`components/wierdtext.tsx`) and the intro car animation (`components/loader.tsx`). No shader, no framer-motion, no 3D tilt — the previous design is kept on the `v1-shader-design` branch/tag.

### Content

All copy lives in two files; edit these and nothing else to change what the page says:

- `lib/data.ts` — `site` (statement, facts, links, colophon), `works`, `education`
- `lib/projects.ts` — the project boxes (title, description, link, year, tags, status)

### Components

- `app/page.tsx` — the single page: statement, Projects, Experience, Education, Contact
- `components/section.tsx` — numbered section header on a hairline
- `components/project-box.tsx`, `components/entry-box.tsx` — boxes in the hairline grid; hover inverts them
- `components/top-bar.tsx` — fixed, no strip behind it, drawn in `mix-blend-mode: difference` so it inverts over whatever scrolls under it
- `components/wierdtext.tsx` — GSAP SplitText + ScrambleText; splits words and chars, chars are `pointer-events: none` (WebKit drops clicks otherwise)
- `components/loader.tsx` — intro; frames in `public/loader`, generated by `scripts/build-loader.mjs` from `assets-src/`

### Style

- Black page, white type, hairlines `rgba(255,255,255,.28)`; no rounded corners, shadows or blur
- Inter, local (`public/fonts/inter`, 400/400i/700/800/900)
- The gallery is a separate repo/site (frankllonch/gallery), deliberately not linked from here
- Path alias `@/` maps to the repo root
